# 🔎 Forensics

Encompasses network traffic analysis (PCAP files), file carving, metadata extraction, memory analysis, steganography (images, audio), and disk filesystem examination.

## 🧰 Essential Tools & Libraries

| Tool / Library | Purpose |
|---|---|
| [Wireshark](https://www.wireshark.org/) / `tshark` | Network packet and protocol analysis |
| [binwalk](https://github.com/ReFirmLabs/binwalk) | Firmware analysis, embedded file signature scanning and extraction |
| [exiftool](https://exiftool.org/) | Metadata inspection and modification for multimedia files |
| [Volatility 3](https://github.com/volatilityfoundation/volatility3) | Memory dump forensics and artifact extraction |
| [zsteg](https://github.com/zed-0xff/zsteg) | Steganography detection in PNG and BMP files |
| [Stegsolve](http://www.caesum.com/handbook/Stegsolve.jar) | Visual image steganography plane inspection |
| `foremost`, `scalpel` | File carving from raw dumps or damaged disks |
