# 🔐 Cryptography

Focuses on classic ciphers (Caesar, Vigenère, Substitution, XOR, Transposition), modern symmetric/asymmetric cryptography (AES, RSA, ECC, Diffie-Hellman), hashing, and PRNG weakness analysis.

## 🧰 Essential Tools & Libraries

| Tool / Library | Purpose |
|---|---|
| [CyberChef](https://gchq.github.io/CyberChef/) | Multi-purpose web tool for encoding, decoding, encryption, and hashing |
| [pycryptodome](https://pycryptodome.readthedocs.io/) | Python cryptographic primitives (AES, RSA, DES, hashes) |
| [SageMath](https://www.sagemath.org/) | Advanced mathematical computation (Coppersmith, LLL, lattice reduction) |
| [RsaCtfTool](https://github.com/RsaCtfTool/RsaCtfTool) | Automated RSA key attacks (Wiener, Boneh-Durfee, Fermat factorization) |
| [FeatherDuster](https://github.com/nccgroup/featherduster) | Automated cryptanalysis tool |
| `hashcat` / `john` | Password and hash recovery |
