# 🛠️ General Skills

Covers foundational Linux shell skills, environment variables, automation scripts, piping/redirection, regex, encodings (Base64, Hex, ASCII, Binary), and basic scripting.

## 🧰 Essential Tools & Commands

| Tool / Command | Purpose |
|---|---|
| `bash` / `zsh` | Shell scripting, loops, pipes, and process substitution |
| `grep`, `sed`, `awk` | Text search, stream editing, data parsing |
| `find`, `locate` | Locating files by permissions, owners, and dates |
| `file`, `xxd`, `hexdump` | File identification and inspecting byte representations |
| `curl`, `wget`, `nc` | Network interactions and raw socket communication |
| `base64`, `tr` | Fast CLI encoding/decoding and character replacement |
| `tmux` / `screen` | Terminal multiplexing for long-running processes |
