# 🔄 Reverse Engineering

Covers decompilation, disassembly, binary patching, static analysis, and dynamic debugging of compiled executables (ELF, PE), bytecode (.NET, Java, Python), and mobile binaries (APK).

## 🧰 Essential Tools & Frameworks

| Tool / Framework | Purpose |
|---|---|
| [Ghidra](https://ghidra-sre.org/) | NSA's free decompiler, disassembler, and reverse engineering suite |
| [IDA Free / Pro](https://hex-rays.com/ida-free/) | Industry-standard disassembler and decompiler |
| [Binary Ninja](https://binary.ninja/) | Modern binary analysis and decompilation platform |
| [x64dbg](https://x64dbg.com/) | Windows x32/x64 ring 3 debugger |
| [GDB](https://www.gnu.org/software/gdb/) + [pwndbg](https://github.com/pwndbg/pwndbg) | Linux binary dynamic debugging |
| [angr](https://angr.io/) | Python symbolic execution engine for path solving |
| [JADX](https://github.com/skylot/jadx) | Dex to Java decompiler for Android APKs |
| [pycdc](https://github.com/zrax/pycdc) / `uncompyle6` | Python bytecode (.pyc) decompilers |
